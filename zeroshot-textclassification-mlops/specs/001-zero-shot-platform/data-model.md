# Data Model: Zero-Shot Text Classification Platform

The platform has no database. Data lives in YAML configuration files, the local model directory, and
MinIO objects. See [config-files.md](contracts/config-files.md) and
[prediction-record.schema.json](contracts/prediction-record.schema.json) for exact formats.

## Entity relationships

```text
ModelConfig 1 ── 0..1 LocalModel
ModelConfig 1 ── 0..* ClassificationRequest
LabelSet    1 ── 0..* ClassificationRequest
ClassificationRequest 1 ── 0..1 PredictionRecord
PredictionRecord 1 ── 2..* RankedLabel
```

Each request records its own copy of the model details and labels. Later edits or deletions therefore do
not change stored predictions.

## ModelConfig

A model the platform supports. Stored in `configs/models.yaml`.

| Field | Type | Rules |
|---|---|---|
| `id` | string | Required and unique. Hugging Face format `org/name`, with no `..`, absolute paths, or backslashes. |
| `name` | string | Required display name. |
| `task` | string | Required. Must be `zero-shot-classification`. |
| `revision` | string | Required. Hugging Face commit hash to download. |

## LocalModel

A model's on-disk state, derived from the model directory rather than stored as its own record.

| Field | Type | Rules |
|---|---|---|
| `model_id` | string | Matches a `ModelConfig.id`. |
| `path` | path | `{MODEL_DIR}/{org}/{name}`, and must resolve inside `MODEL_DIR`. |
| `status` | enum | See the state transitions below. |
| `revision` | string or null | Read from the completion marker. |
| `downloaded_at` | UTC timestamp or null | Read from the completion marker. |
| `error` | string or null | Latest failure message, with no secrets. |

**Completion marker**: `{path}/.download-complete.json` contains `model_id`, `revision`, and `downloaded_at`.

### Status transitions

```text
not_downloaded ──download──▶ downloading ──success──▶ ready
      ▲                          │                      │
      │                        failure                delete
      │                          ▼                      │
      ├──────retry────────────  failed                  │
      └─────────────────────────────────────────────────┘
```

- `ready` requires both the final folder and a valid completion marker.
- `downloading` is held by a lock file at `{MODEL_DIR}/.tmp/{safe_id}.lock`. A second download of the same
  model is refused. A lock whose owning process is gone is treated as stale and removed.
- `failed` is recorded at `{MODEL_DIR}/.tmp/{safe_id}.failed.json`, after temporary files are removed. A
  retry starts from `not_downloaded` behavior and clears this record.
- A marker-less folder at the final path is never `ready`, and is reported as `failed`.

## LabelSet

A named group of candidate labels. Stored in `configs/labels.yaml`.

| Field | Type | Rules |
|---|---|---|
| `name` | string | Required and unique after trimming, ignoring case. |
| `labels` | list of strings | At least 2 labels. Each is trimmed and non-empty. No case-insensitive duplicates. |

The file also has `default`, the name of the set preselected on the classification page. It must match an
existing set. Saves write to a temporary file and then replace the original, so a failed save cannot corrupt it.

## ClassificationRequest

One submission, held in memory only. It is not persisted unless it succeeds.

| Field | Type | Rules |
|---|---|---|
| `request_id` | UUID4 string | Generated by the system and unique. |
| `text` | string | Not empty after trimming, and at most `MAX_INPUT_CHARS` characters (default 10,000). |
| `model_id` | string | Must refer to a `ready` model at submission time. |
| `labels` | list of strings | Must pass the LabelSet rules. |
| `session_id` | string or null | Optional identifier for the Streamlit session. |

## PredictionRecord

The result of one successful classification, stored once in MinIO. It is not updated after being written.

**Location**: `{MINIO_BUCKET}/predictions/YYYY/MM/DD/{request_id}.json`, using the UTC date of `timestamp`.

| Field | Type | Required | Notes |
|---|---|---|---|
| `request_id` | UUID4 string | Yes | Same as the object's file name. |
| `timestamp` | UTC ISO 8601 string | Yes | For example, `2026-10-31T12:00:00Z`. |
| `input_text` | string | Yes | Full submitted text. |
| `predicted_class` | string | Yes | Must equal `ranked_predictions[0].label`. |
| `confidence` | number 0–1 | Yes | Must equal `ranked_predictions[0].score`. |
| `candidate_labels` | list of strings | Yes | Labels as submitted. |
| `ranked_predictions` | list of RankedLabel | Yes | Sorted by descending score, with one entry per candidate label. |
| `model_name` | string | Yes | From `ModelConfig.name`. |
| `model` | string | Yes | Hugging Face identifier. |
| `model_revision` | string or null | Yes | Null only when the revision is unavailable. |
| `application_version` | string | Yes | From `APP_VERSION`. |
| `session_id` | string or null | No | Optional. |
| `latency_ms` | number or null | No | Inference duration. |

The stored field names follow the assignment's JSON example, plus `model_name` for the required model name.

## RankedLabel

| Field | Type | Rules |
|---|---|---|
| `label` | string | One of the record's candidate labels. |
| `score` | number 0–1 | Unrounded model score. The UI rounds it for display. |
